欢迎部署 Cloudflare Drive Player

检测到您的项目尚未在 Cloudflare Pages 中配置 Google Service Account 凭据。请完成以下两步即可开启使用：

1
在 Google Cloud 控制台创建服务账号 (Service Account) 并生成 JSON 密钥，同时将你的 Google 云端硬盘（或文件夹）共享给该服务账号邮箱。
2
进入 Cloudflare Dashboard -> Pages -> 你的项目 -> Settings -> Environment Variables，添加变量：
SERVICE_ACCOUNT_JSON = {"type": "service_account", ...}
（可选）ROOT_FOLDER_ID = 你的根文件夹ID
